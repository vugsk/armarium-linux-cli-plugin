# Настройки armarium

Скиллы armarium берут пути к хранилищу Obsidian и к стандартам из файла настроек, а не из текста скилла. Эту справку читают скиллы; ссылка на неё в скилле идёт от папки самого скилла (`../../docs/settings.md`).

## Файл настроек

`~/.claude/armarium.json` (`~` — домашняя папка пользователя):

```json
{
  "version": 1,
  "vault": "~/Documents/MyVault"
}
```

- `version` — номер схемы файла (сейчас 1).
- `vault` — корень хранилища Obsidian. `~` в начале значения раскрывается как домашняя папка.

Прочитай файл (`Read`) в начале работы и дальше используй `<vault>` — значение поля `vault` с раскрытым `~`.

## Раскладка хранилища (фиксированная)

Всё остальное выводится из `<vault>`:

- стандарты: `<vault>/Проекты/Стандарт по названию проектов.md`, `<vault>/Проекты/Стандарт по названию устройств.md`, `<vault>/Проекты/Стандарт проектных заметок.md`;
- карта проектов: `<vault>/Проекты/Карта проектов.md`;
- заметки проекта: `<vault>/Проекты/<кодовое слово>/`;
- копия скиллов: `<vault>/Документация/Скиллы Claude/`.

## Если файла нет или он повреждён

- Файла нет: скажи пользователю одной фразой, что файл настроек `~/.claude/armarium.json` не найден, и спроси путь к корню хранилища (мастер настройки, который должен создавать этот файл, появится позже). Продолжай работу с этим путём, но **ничего не записывай** в файл настроек сам.
- Файл есть, но это не JSON, нет поля `vault` или `version` неизвестна: не угадывай, сообщи, что именно не так, и спроси путь.
- По указанному пути нет папки `Проекты` или нужного стандарта: не подставляй другой путь, сообщи, какого файла нет, и спроси пользователя.
