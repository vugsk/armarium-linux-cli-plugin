# NASM (ассемблер x86)

**Темы:** синтаксис Intel, секции (`.text`, `.data`, `.bss`), регистры общего назначения, режимы адресации, стек и кадры вызовов, соглашения о вызовах (System V AMD64 на Linux, Microsoft x64 на Windows), системные вызовы, флаги и условные переходы, форматы объектных файлов (`elf64`, `win64`) и линковка.

**Спроси сначала:** целевую ОС и разрядность (Linux или Windows, 32 или 64 бита), потому что соглашения о вызовах и системные вызовы различаются.

**Где смотреть:** документация NASM (The Netwide Assembler manual), Intel Software Developer's Manual для инструкций, документ System V ABI для Linux.

**Проверяй, не вспоминай:** номера системных вызовов, порядок аргументов в регистрах и правила выравнивания стека — по документации для его ОС и ABI, а не по памяти. Ошибка в них даёт аварийное завершение без внятного сообщения.

**Примеры на другой задаче:** показывай приём на простой арифметике или копировании небольшого массива, а не на его конкретной программе.
