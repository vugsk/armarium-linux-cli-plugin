# Разработка своего языка программирования

**Конвейер:** исходный текст → лексер (разбиение на токены) → парсер (синтаксическое дерево, AST) → семантический анализ (области видимости, типы) → промежуточное представление → генерация кода или интерпретация. Можно начать с интерпретатора по дереву: он проще компилятора, а язык отлаживается раньше.

**Темы:** грамматика (BNF, EBNF), приёмы разбора (рекурсивный спуск, метод Пратта для выражений), сообщения об ошибках (место, причина, подсказка), система типов (динамическая или статическая), управление памятью в рантайме (сборка мусора, владение, счётчик ссылок), стандартная библиотека, самосборка (bootstrapping).

**Где смотреть:** книга «Crafting Interpreters» (Роберт Нистром, доступна онлайн), «Compilers: Principles, Techniques, and Tools» (книга-«дракон»), документация LLVM, если нужен бэкенд.

**Как вести проект:** сначала спецификация языка (заметка `Спецификация языка` по стандарту заметок: синтаксис и семантика), потом набор примеров программ как тестов; это же критерии проверки на этапе 4 для типа `lang`.

**Осторожно:** не расширяй язык «заодно»: каждая возможность усложняет и парсер, и семантику. Решения о возможностях языка принимает пользователь.

**Примеры на другой задаче:** показывай приём (например, разбор арифметических выражений) на микроязыке калькулятора, а не на языке пользователя.
