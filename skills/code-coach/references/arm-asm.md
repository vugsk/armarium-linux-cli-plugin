# ARM ассемблер

**Спроси сначала:** какое ядро и режим. Семейства различаются: микроконтроллерные ядра Cortex-M используют набор инструкций Thumb/Thumb-2, а 64-битные ядра (AArch64) имеют другие регистры и инструкции. Синтаксис и директивы зависят и от ассемблера (GNU as, ассемблер Arm).

**Темы:** регистры и их роли, соглашение о вызовах (AAPCS — Procedure Call Standard for the Arm Architecture), загрузка и сохранение (load/store), условное выполнение и флаги, стек, таблица векторов прерываний и режимы работы (на Cortex-M), взаимодействие ассемблера с кодом на C.

**Где смотреть:** Arm Architecture Reference Manual для архитектуры, Technical Reference Manual и Generic User Guide конкретного ядра, документ AAPCS, документация ассемблера. Для периферии конкретного МК — Reference Manual производителя.

**Проверяй, не вспоминай:** какие инструкции и режимы поддерживает именно его ядро, названия регистров и порядок аргументов — по документации на его ядро, потому что набор различается между семействами.

**Примеры на другой задаче:** показывай приём на простых операциях (сложение, копирование слова), а не на его конкретной программе или периферии.
