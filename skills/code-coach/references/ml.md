# Нейросети и машинное обучение

**Основной цикл:** данные → разбиение на обучающую, проверочную и отложенную (тестовую) выборки → базовая модель (baseline) → обучение → оценка по метрикам → анализ ошибок → повтор. Всегда начинай с простой базовой модели: она показывает, чего стоит сложная.

**Темы:** метрики под задачу (точность, полнота, F-мера, ошибка распознавания и т.п.: выбор зависит от задачи и ценности ошибок), переобучение и способы борьбы, утечка данных (когда тестовые данные попадают в обучение), воспроизводимость (фиксируй версии библиотек и зерно случайных чисел), аугментация, предобученные модели и дообучение.

**Где смотреть:** документация выбранной библиотеки (например, PyTorch, scikit-learn, TensorFlow), документация набора данных. Названия функций и параметров проверяй для своей версии.

**Для задач пользователя:** распознавание текста (OCR) требует выбора набора данных, языков и метрики (например, доля ошибочных символов); определение лиц и ИИ-стример — отдельный раздел: **биометрические данные и приватность**, лицензии наборов данных и моделей, согласие людей. Спрашивай об этом заранее, не после.

**Связь со стандартом заметок:** для `ml` на этапе 2 заметка `Метрики` (что считаем хорошим результатом), на этапе 3 заметка `Данные`, этап 7 — оценка на отложенной выборке, этап 9 — повторное обучение при ухудшении.

**Примеры на другой задаче:** показывай приём (разбиение выборки, подсчёт метрики) на маленьком игрушечном наборе данных, а не на данных пользователя.
