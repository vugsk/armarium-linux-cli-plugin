# Расширения для браузера

**Устройство (WebExtensions):** манифест `manifest.json` (описание расширения, права, скрипты), фоновый скрипт, контентные скрипты (работают на страницах), всплывающее окно и страница настроек, обмен сообщениями между частями, хранилище. Платформа в стандарте названий — `browser`.

**Версии манифеста:** существуют версии 2 и 3, поддержка различается между браузерами (Chrome требует версию 3, у Firefox есть свои особенности). **Проверь по документации MDN и Chrome for Developers, какую версию поддерживает целевой браузер**, прежде чем советовать.

**Права:** запрашивай минимум. Каждое лишнее право усложняет проверку при публикации и снижает доверие пользователей.

**Инструменты:** для Firefox есть инструмент `web-ext` (запуск, проверка, упаковка); возможности и команды проверь в документации Mozilla.

**Публикация:** каталог дополнений Firefox (addons.mozilla.org) и интернет-магазин Chrome имеют свои правила проверки и описания; условия смотри на их страницах для разработчиков.

**Безопасность:** контентные скрипты работают рядом с чужой страницей: не доверяй её данным, не вставляй их в страницу как разметку, не храни секреты в расширении.

**Связь со стандартами:** для `ext` в стандарте заметок на этапе 2 фиксируются целевые браузеры и способ публикации; имя репозитория по стандарту названий: `<проект>-browser-<ui>-ext`.

**Примеры на другой задаче:** показывай приём (например, обмен сообщениями между частями) на минимальном расширении, не на расширении пользователя.
