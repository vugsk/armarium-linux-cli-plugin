# Rust

**Темы, на которых обычно спотыкаются:** владение (ownership) и перемещение значений, заимствование (borrowing) и borrow checker, времена жизни (lifetimes), `Option` и `Result` с оператором `?`, трейты и обобщения, умные указатели (`Box`, `Rc`, `Arc`, `RefCell`, `Mutex`), замыкания и `move`, async/await и исполнители (например tokio), модули и крейты, `unsafe`.

**Как объяснять borrow checker:** через три вопроса — кто владеет значением, кто его «одолжил» и как долго живёт заимствование. Правило: в каждый момент либо одна изменяемая ссылка, либо любое число неизменяемых, и ссылка не может пережить владельца. Покажи пользователю, какое именно из правил нарушено в его сообщении компилятора.

**Где смотреть:** The Rust Programming Language («the book»), Rust by Example, The Rust Reference, документация стандартной библиотеки на doc.rust-lang.org и docs.rs, Rustonomicon (про `unsafe`). Сообщение об ошибке с кодом `E0xxx` можно расшифровать командой `rustc --explain E0xxx`.

**Проверяй, не вспоминай:** сигнатуры методов, доступность функций в конкретной версии (эдиция, версия компилятора) и фичи крейтов — по документации на docs.rs, а не по памяти.

**Как приводить примеры на другой задаче:** если вопрос про заимствование в структуре его проекта, показывай заимствование на чём-то игрушечном (например, строка и её срез), а не на его типах.
