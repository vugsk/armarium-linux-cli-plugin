# Java

**Темы:** классы, интерфейсы, наследование и полиморфизм, обобщения и стирание типов, коллекции, исключения (проверяемые и непроверяемые), многопоточность и `java.util.concurrent`, память и сборка мусора, потоки данных (Streams), сборка и зависимости (Maven, Gradle).

**Версия важна:** возможности языка (например, записи, закрытые иерархии, шаблоны) зависят от версии JDK. Спрашивай версию, если ответ от неё зависит.

**Где смотреть:** The Java Language Specification, документация OpenJDK и Oracle, Javadoc стандартной библиотеки.

**Как объяснять:** опирайся на то, что пользователь уже знает из Rust и C++ (владение, шаблоны), и отмечай отличия: в Java объекты управляются сборщиком мусора, а не владением, обобщения реализованы стиранием типов.

**Примеры на другой задаче:** показывай приём на простых классах (список, строка), а не на типах его проекта.
