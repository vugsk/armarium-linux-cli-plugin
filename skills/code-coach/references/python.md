# Python

**Темы:** изменяемые и неизменяемые объекты, ссылки и копирование, области видимости и замыкания, итераторы и генераторы, исключения, контекстные менеджеры (`with`), классы и протоколы, типизация (`typing`), asyncio (цикл событий, корутины, `await`), виртуальные окружения и зависимости, многопоточность и ограничение GIL в стандартном CPython.

**Версия важна:** набор возможностей и поведение зависят от версии Python (например, сопоставление с образцом, улучшения asyncio). Спрашивай версию, если ответ от неё зависит.

**Где смотреть:** docs.python.org (язык, стандартная библиотека, учебник), PEP для подробностей решений в языке, документация библиотек (для Telegram-ботов — документация выбранной библиотеки).

**Осторожно с asyncio:** путаница «блокирующий вызов внутри корутины» — частая причина «всё встало». Объясняй, что именно блокирует цикл событий, и где искать неблокирующий вариант.

**Примеры на другой задаче:** показывай идею на простых объектах (список, словарь, строка), а не на данных его бота.
