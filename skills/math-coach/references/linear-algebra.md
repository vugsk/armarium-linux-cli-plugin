# Линейная алгебра для программирования

*Справка написана 2026-11-04. Соглашения (вектор-столбец или строка, порядок хранения матрицы, правая или левая система) у библиотек разные — проверяй по документации нужной.*

**Векторы:** точка (положение) и вектор (направление и длина) — разные вещи, хотя хранятся одинаково; в однородных координатах точка имеет w = 1, вектор w = 0, поэтому перенос не действует на направления.
- сложение, умножение на число, длина ‖v‖ = √(x² + y² + z²), нормализация v / ‖v‖ (проверка на нулевую длину);
- скалярное произведение a·b = ‖a‖‖b‖cos θ: угол, проекция, «спереди или сзади», освещение;
- векторное произведение a × b (только 3D): перпендикуляр, площадь параллелограмма; формула одна и та же, а от правой или левой системы зависит, как результат выглядит в пространстве (правило правой или левой руки).

**Матрицы как преобразования:** при векторах-столбцах столбцы матрицы — куда переходят базисные векторы (при векторах-строках — строки). Масштаб, поворот, сдвиг (shear) — 3×3; с переносом — 4×4 в однородных координатах.
- композиция — произведение матриц; порядок важен: при векторах-столбцах M = T·R·S применяется справа налево (сначала масштаб, потом поворот, потом перенос);
- обратная матрица — обратное преобразование; для поворота она равна транспонированной;
- определитель: изменение площади или объёма, знак — отражение, ноль — вырожденность.

**Системы координат и базисы:** локальная, мировая, камеры; переход между ними — матрица смены базиса. Матрица вида — обратная к матрице камеры в мире. Нормали преобразуются обратной транспонированной матрицей (при неравномерном масштабе иначе они перестают быть перпендикулярны поверхности).

**Хранение в памяти:** по строкам или по столбцам (row-major / column-major) — вопрос хранения, не математики; его путают с векторами-строками и столбцами. Что ждёт API или шейдер — по документации.

**Решение систем:** метод Гаусса, LU-разложение; для малых систем в играх обычно хватает явных формул, для больших — библиотеки линейной алгебры.

**Собственные векторы и SVD** — для анализа данных (PCA), устойчивых решений, ориентированных ограничивающих объёмов; на уровне идеи — направления, которые преобразование только растягивает.

**Где смотреть:** серия видео «Essence of Linear Algebra» (3Blue1Brown), «3D Math Primer for Graphics and Game Development» (Dunn, Parberry, доступна онлайн), «Mathematics for 3D Game Programming and Computer Graphics» (Lengyel).

**Пример на числах:** поворот (1, 0) на 90° против часовой: матрица [[0, −1], [1, 0]] даёт (0, 1).
