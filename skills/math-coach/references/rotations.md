# Повороты: углы Эйлера, ось-угол, кватернионы

*Справка написана 2026-11-04. Порядок осей, знак угла и порядок компонент кватерниона (w первым или последним) в библиотеках разные — по документации нужной.*

**Углы Эйлера** (рыскание, тангаж, крен): удобно для человека и интерфейса; результат зависит от порядка осей (12 порядков, каждый во внутреннем или внешнем варианте — 24 соглашения); **складывание рамок** (gimbal lock) — при определённом угле две оси совпадают, и одна степень свободы теряется. Интерполировать углы покомпонентно — даёт кривой путь.

**Ось и угол:** поворот на θ вокруг единичной оси n; формула Родрига переводит в матрицу.

**Кватернион** q = (w, x, y, z) = (cos(θ/2), n·sin(θ/2)) для поворота на θ вокруг оси n:
- поворот описывают только единичные кватернионы; после многих умножений нормализуют;
- композиция — произведение q₂·q₁ (сначала q₁) в соглашении Гамильтона; в соглашении JPL порядок обратный — смотри документацию библиотеки; произведение некоммутативно;
- поворот вектора v: q·(0, v)·q⁻¹, для единичного q⁻¹ = сопряжённый (w, −x, −y, −z);
- q и −q задают один и тот же поворот — при интерполяции выбирают тот, у которого скалярное произведение с начальным ≥ 0 (короткий путь);
- нет складывания рамок, 4 числа вместо 9, дешёвая композиция.

**Интерполяция:** slerp — равномерное движение по дуге (постоянная угловая скорость); nlerp (линейная с нормализацией) — дешевле, скорость чуть неравномерна, для малых углов почти неотличима.

**Матрица поворота:** 9 чисел, ортонормальная (столбцы единичные и перпендикулярны), определитель 1; накопленная ошибка лечится ортонормализацией (Грам — Шмидт).

**Что когда:** хранение ориентации и анимация — кватернион; передача в шейдер и преобразование многих точек — матрица; ввод от пользователя и редактор — углы Эйлера, с переводом.

**2D:** поворот — один угол или комплексное число (cos θ, sin θ); кватернионы не нужны.

**Где смотреть:** «3D Math Primer for Graphics and Game Development» (главы об ориентации), интерактивные видео о кватернионах Ben Eater и 3Blue1Brown, 2018 (eater.net/quaternions).

**Пример на числах:** поворот на 90° вокруг Z: q = (cos 45°, 0, 0, sin 45°) ≈ (0,707; 0; 0; 0,707); вектор (1, 0, 0) переходит в (0, 1, 0).
