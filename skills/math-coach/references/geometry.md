# Геометрия: пересечения, расстояния, объёмы, кривые

*Справка написана 2026-11-04. Формулы проверяй по «Real-Time Collision Detection» (Christer Ericson) или другому названному источнику; использование в движке — `physics-coach`.*

**Прямые, лучи, плоскости:** луч p(t) = o + t·v, t ≥ 0 (o — начало, v — направление); плоскость n·x = d (n — единичная нормаль, d — число, расстояние от начала координат). Пересечение луча с плоскостью: t = (d − n·o) / (n·v), при n·v ≈ 0 луч параллелен плоскости.

**Расстояния:** от точки до плоскости — n·p − d (со знаком: по какую сторону); до отрезка — проекция с ограничением параметра в [0, 1]; между отрезками — минимизация по двум параметрам.

**Треугольник:** нормаль — (b − a) × (c − a); барицентрические координаты (u, v, w), u + v + w = 1: внутри треугольника, если все ≥ 0; интерполяция атрибутов. Пересечение луча с треугольником — алгоритм Мёллера — Трумбора.

**Ограничивающие объёмы:** сфера (центр и радиус — проверка дешевле всего), AABB (выровненный по осям параллелепипед — пересечение сравнением границ по каждой оси), OBB (ориентированный — теорема о разделяющей оси), выпуклая оболочка. Пересечение луча с AABB — метод «плит» (slab).

**Выпуклость и разделяющая ось:** два выпуклых тела не пересекаются, если есть ось, на которую их проекции не перекрываются; основа SAT. GJK работает через разность Минковского — подробности в источнике.

**Многоугольники в 2D:** ориентация трёх точек по знаку векторного произведения (по часовой или против), точка внутри многоугольника (подсчёт пересечений луча), площадь (формула площади Гаусса, «шнурков»), триангуляция.

**Кривые:** Безье (контрольные точки, алгоритм де Кастельжо), сплайн Катмулла — Рома (проходит через внутренние точки, крайние задают касательные; удобен для путей камеры), B-сплайны; параметр t не равен длине пути — для равномерного движения нужна перепараметризация по длине.

**Пространственное разбиение** (для многих объектов): равномерная сетка, квадродерево и октодерево, BVH, k-d-дерево — компромисс построения и запроса.

**Точность:** сравнения с допуском (эпсилон), вырожденные случаи (параллельность, нулевая длина) обрабатываются явно — см. `numerics.md`.

**Пример на числах:** луч из (0, 0, 0) по v = (0, 0, 1) и плоскость z = 5 (n = (0, 0, 1), d = 5): t = 5, точка (0, 0, 5).
