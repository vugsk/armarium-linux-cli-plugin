# Общие строки .gitignore и tests/

В файл `.gitignore` каждая строка идёт с комментарием, зачем она (на русском).

**Общие строки для любого проекта:**
- `.idea/` — настройки JetBrains (RustRover и др.), у каждого свои;
- `.vscode/` — настройки редактора;
- `.env` — секреты (токены, пароли), в репозиторий попадать не должны; рядом кладётся `.env.example` без значений;
- `*.log` — журналы работы;
- `*.swp` — временные файлы редактора.

**Устройство (KiCad), проверь для своей версии KiCad:**
- `*-backups/` — автоматические резервные копии проекта;
- `_autosave-*` — автосохранения;
- `*.kicad_prl` — локальные настройки проекта (положение окон и т.п.);
- `fp-info-cache` — кэш библиотек посадочных мест.
Файлы Gerber, STL и STEP в историю не кладутся: они выкладываются в Releases.

**`tests/README.md`:** одна-две фразы: «Тесты проекта. Пишутся скиллом `test-plan`: каждый тест отдельным файлом, в начале файла комментарий, зачем тест».
