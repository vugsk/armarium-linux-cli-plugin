# ARM ассемблер

**Шаблона hello-world нет.** Он зависит от ядра и режима: микроконтроллер Cortex-M (Thumb), 64-битное ядро AArch64, Linux или голое железо; вывод на МК требует платы и настройки периферии. Не придумывай код, спроси ядро, ассемблер (GNU as, ассемблер Arm) и тулчейн.

**Что создавать по умолчанию:** README со скелетом, `.gitignore`, `src/` (пустая папка с короткой заметкой в `README`), `tests/`.

**`.gitignore`:** `*.o`, `*.elf`, `*.bin`, `*.hex`, `*.map` (результаты сборки и линковки).

Когда пользователь назовёт ядро и тулчейн, можно создать минимальный файл по документации на это ядро (Arm Architecture Reference Manual, документация тулчейна), помечая в ответе, что синтаксис проверен только по документации. Объяснения по ассемблеру — скилл `code-coach`.
