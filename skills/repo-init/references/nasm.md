# NASM (ассемблер x86)

**Спроси сначала:** ОС и разрядность. Шаблон ниже — **Linux, x86-64**; для другой ОС номера системных вызовов и соглашения другие, не придумывай их: скажи, что шаблона нет, и создай только структуру.

**Файлы:** `src/hello.asm`.

**`src/hello.asm`** (Linux, x86-64; номера системных вызовов проверь по документации для своей ОС):
```nasm
; Данные: строка и её длина.
section .data
msg db "Hello, world!", 10   ; 10 — код перевода строки
len equ $ - msg              ; длина строки: текущий адрес минус адрес начала

; Код программы.
section .text
global _start                ; точка входа для линковщика
_start:
    mov rax, 1               ; номер системного вызова write
    mov rdi, 1               ; куда писать: 1 — стандартный вывод
    mov rsi, msg             ; что писать: адрес строки
    mov rdx, len             ; сколько байт
    syscall                  ; вызвать ядро

    mov rax, 60              ; номер системного вызова exit
    xor rdi, rdi             ; код возврата 0 (обнуление регистра)
    syscall
```

**`.gitignore`:** `*.o` (объектные файлы) и имя собранного файла, например `hello`.

**Проверка:** `nasm -f elf64 src/hello.asm -o hello.o && ld hello.o -o hello && ./hello`.
