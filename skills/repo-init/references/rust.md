# Rust

**Файлы:** `Cargo.toml`, `src/main.rs`. Cargo.lock для программ (бинарных проектов) в репозиторий коммитится.

**`Cargo.toml`** (с комментариями): раздел `[package]` с `name` = техническое имя проекта (допустимы строчные буквы, цифры, дефисы и подчёркивания), `version = "0.1.0"`, `edition`. **Эдицию не угадывай:** спроси версию компилятора (`rustc --version`) и проверь по документации Cargo, какую эдицию указывать. Пустой раздел `[dependencies]`.

**`src/main.rs`:**
```rust
// Точка входа программы: выполнение начинается с функции main.
fn main() {
    // println! печатает строку в стандартный вывод (макрос, поэтому с «!»).
    println!("Hello, world!");
}
```

**`.gitignore`:** `/target` — каталог сборки (в нём всё, что создаёт cargo).

**Проверка:** `cargo run`.
