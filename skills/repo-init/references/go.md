# Go

**Файлы:** `main.go`. **`go.mod` не пиши вручную:** в нём указывается версия Go, которой ты не знаешь. Дай пользователю команду `go mod init <путь модуля>` (выполняет он сам) и объясни, что она делает.

**`main.go`:**
```go
// Каждый исполняемый файл Go принадлежит пакету main.
package main

// Подключаем пакет форматированного вывода.
import "fmt"

// Точка входа программы.
func main() {
	// Println печатает строку и переводит строку.
	fmt.Println("Hello, world!")
}
```

**`.gitignore`:** `/bin/` (собранные файлы), `*.exe`. Имя собранного бинарника добавь, если оно известно.

**Проверка:** `go run .` (после `go mod init`).
