# Ограничения и контакты глубоко: решатели, многообразия, GJK и EPA, время удара

*Справка написана 2026-11-04 по общим принципам; формулы перед опорой на них сверяй с названными источниками. Линейная алгебра под формулами (якобиан, обратная матрица, системы уравнений) — `math-coach`.*

**Ограничение в скоростях:** ограничение задаётся функцией положений C(x) = 0 (равенство: шарнир, расстояние) или C(x) ≥ 0 (неравенство: контакт, предел). Его производная по времени Ċ = J·v, где v — все скорости тел (линейные и угловые), J — якобиан ограничения (строка на каждое скалярное условие). Решатель ищет импульс λ вдоль Jᵀ:
- изменение скоростей: v ← v + M⁻¹·Jᵀ·λ, M — матрица масс и инерций;
- эффективная масса: m_eff = (J·M⁻¹·Jᵀ)⁻¹;
- импульс: λ = −m_eff·(J·v + b), где b — смещение: коррекция дрейфа (Baumgarte, b = (β/dt)·C, здесь β безразмерный, 0…1; у Catto 2005 запись J·V = −β·C, там β в 1/с) и упругость контакта.

**Неравенства и накопление:** для контакта суммарный импульс за шаг не может тянуть тела друг к другу (λ ≥ 0). Ограничивают **накопленный** импульс, а не приращение: λ_накоп ← max(0, λ_накоп + Δλ), применяют разницу. Это даёт устойчивые стопки и позволяет тёплый старт (Catto, «Sequential Impulses», GDC 2006; основа — «Iterative Dynamics with Temporal Coherence», 2005).

**Трение:** импульсы по касательным ограничены |λ_t| ≤ μ·λ_n (в статье 2005 года граница постоянная, μ·m_c·g; привязка к текущему нормальному импульсу — в последующих докладах) (пирамида трения — по двум осям отдельно, проще; конус — точнее). Трение качения и вращения — отдельные ограничения.

**Последовательные импульсы и PGS:** обход ограничений по очереди, несколько итераций за шаг; это метод проецированного Гаусса — Зейделя для задачи дополнительности (LCP). Сходимость зависит от порядка и отношения масс: тяжёлое тело на лёгком — трудный случай.

**Коррекция дрейфа:** Baumgarte (смещение в скорость, добавляет энергию), разделённые импульсы (split impulse — отдельная скорость только для коррекции положения), нелинейный Гаусс — Зейдель по положениям.

**Мягкие ограничения:** ограничение задаётся частотой f (Гц, ω = 2πf) и коэффициентом затухания ζ (damping ratio) вместо «магических» β и CFM/ERP; поведение меньше зависит от шага и числа итераций (Catto, «Soft Constraints», GDC 2011; подход «Soft Step» в Box2D v3 — по блогу box2d.org). Связь с пружиной с демпфером — через неявное интегрирование.

**Динамика на положениях (XPBD):** ограничения решаются прямо по положениям, с податливостью α (обратная жёсткость); приращение Δλ = (−C − α̃·λ) / (∇C·M⁻¹·∇Cᵀ + α̃), α̃ = α / dt²; скорость — из разницы положений (Macklin, Müller, Chentanez, «XPBD», 2016). Подшаги вместо итераций («Small Steps in Physics Simulation», 2019).

**Контактное многообразие (3D, коробки и многогранники):** по SAT найти ось наименьшего проникновения → опорная грань одного тела и встречная грань другого → отсечь встречную грань боковыми плоскостями опорной (алгоритм Сазерленда — Ходжмена) → оставить точки под опорной гранью → сократить до 4 точек (максимальная площадь). **Идентификаторы признаков** (какие рёбра и грани дали точку) нужны, чтобы сопоставить точки между кадрами для тёплого старта.

**GJK:** расстояние между выпуклыми телами через разность Минковского A − B = A ⊕ (−B) (знак ⊖ не используй: в морфологии это эрозия) и опорную функцию support(d) = самая дальняя точка тела в направлении d; симплекс (точка, отрезок, треугольник, тетраэдр) приближается к началу координат; начало внутри разности — тела пересекаются. **EPA** — продолжение при пересечении: многогранник раздувается до границы разности, ближайшая грань даёт нормаль и глубину. Тонкости — точность у касания, вырожденные симплексы, «полые» формы со скруглением (радиус) для устойчивости. Источник: van den Bergen, «Collision Detection in Interactive 3D Environments»; Ericson.

**Время удара (CCD):** найти момент t ∈ [0, dt] первого касания — консервативное продвижение (шагать на расстояние / верхнюю границу скорости сближения), sweep-тесты для простых форм; обработка — остановить тело в момент удара и доделать шаг подшагами. Вращение усложняет: границы скорости точек учитывают угловую скорость.

**Острова и параллелизм:** граф «тела — ограничения»; связные компоненты решаются независимо и засыпают вместе. Внутри острова — раскраска графа ограничений: ограничения одного цвета не делят тела и решаются параллельно (в том числе SIMD по 4–8 ограничений).

**Вращение вытянутых тел:** явное интегрирование угловой скорости с гироскопическим членом ω × (I·ω) набирает энергию; применяют неявный шаг для этого члена (Catto, «Numerical Methods», GDC 2015).

**Детерминизм:** одинаковый порядок пар и ограничений (сортировка по идентификаторам, не по адресам и хэшам), одинаковые операции с плавающей точкой (без `fast-math`; слияние в FMA меняет результат — в C и C++ запрещают `-ffp-contract=off`; `sqrt` по IEEE 754 точен, а `sin`, `atan2` и другие трансцендентные функции у разных библиотек дают разные последние биты — свои реализации), одинаковое число потоков или порядок, не зависящий от потоков.

**Где смотреть:** публикации Катто (box2d.org), Erleben, «Stable, Robust, and Versatile Multibody Dynamics Animation» (диссертация, 2004), Bender, Müller, Macklin — обзоры по PBD, «Real-Time Collision Detection» (Ericson).
