# Твёрдые тела, ограничения, мягкие тела, выбор движка

*Справка написана 2026-11-04 по общим принципам; формулы — по «Game Physics Engine Development» (Millington), докладам Эрина Катто (GDC, «Iterative Dynamics», «Sequential Impulses») и его блогу о решателе «Soft Step» в Box2D v3.0 (box2d.org, 2024) и «Physically Based Modeling» (Witkin, Baraff, SIGGRAPH). Возможности готовых движков — по их документации нужной версии.*

**Твёрдое тело:** масса и **обратная масса** (0 — неподвижное тело), центр масс, тензор инерции (в локальной системе, в мир переводится поворотом), линейная и угловая скорость, ориентация (кватернион; его математика — `math-coach`). Сила в точке вне центра масс даёт момент: τ = r × F. Угловое ускорение — через обратный тензор инерции.

**Ограничения (constraints):** условие, которое должно выполняться — «расстояние между точками = L» (стержень), «точки совпадают» (шарнир), «угол в пределах» (сустав), контакт без проникновения. Решатель подбирает импульсы, чтобы условия выполнялись.

**Решатели:**
- последовательные импульсы / проецированный Гаусс — Зейдель: по очереди для каждого ограничения, несколько итераций за шаг; больше итераций — жёстче, но дороже;
- тёплый старт: начинать с импульсов прошлого шага — стопки стабильнее;
- коррекция положения: Baumgarte (смещение в скорость) — просто, но может добавлять энергию; разделённые импульсы (псевдоскорости) и нелинейный Гаусс — Зейдель по положениям исправляют дрейф без лишней энергии;
- подшаги (несколько малых шагов вместо итераций) — современный приём для жёстких систем.

**Засыпание:** тела, долго почти неподвижные, выключаются из расчёта до касания — экономия и меньше дрожания.

**Частицы и мягкие тела:**
- частицы: только положение и скорость; эмиттеры, время жизни; для эффектов — без столкновений друг с другом;
- пружины (закон Гука F = −k·Δx с демпфированием): верёвки, ткань, «желе»; жёсткие пружины требуют малого шага;
- динамика на положениях (PBD, XPBD): Верле + проекция ограничений расстояний — устойчиво для верёвок и ткани;
- жидкость: SPH (частицы) или сетка; для игр — упрощения.

**Свой код или готовый движок:** своя физика — ради учёбы или простых правил (платформер на AABB); готовый движок — когда нужны стопки, соединения, сложные формы. Сравнение по 2D или 3D, языку, детерминизму, лицензии, живости проекта; кандидатов проверяет `dependency-audit`, решает пользователь, запись — `Решения`.

**Где смотреть:** Box2D — исходники и статьи Эрина Катто как учебный материал (лицензия проекта — по его репозиторию), «Game Physics Engine Development», «Real-Time Collision Detection».

**Пример на другой задаче:** маятник: точка на стержне длины 1 м от неподвижной опоры, одно ограничение расстояния.
