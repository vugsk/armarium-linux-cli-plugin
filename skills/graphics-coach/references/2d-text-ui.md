# 2D, спрайты, текст, интерфейс, визуализация

*Справка написана 2026-11-04 по общим принципам; возможности конкретных библиотек 2D, шрифтов и GUI — по их документации нужной версии.*

**2D на GPU:** спрайт — прямоугольник из двух треугольников с текстурой; ортографическая проекция в пикселях; пакетная отрисовка (много спрайтов одним вызовом) и атласы, чтобы реже переключать текстуры; порядок по слою и глубине; пиксель-арт — фильтрация «ближайший сосед», целочисленный масштаб, привязка камеры к пикселям, иначе «дрожание».

**Программная 2D-отрисовка (на CPU):** буфер пикселей, линии (Брезенхэм), заливка, наложение с альфой; полезно для учёбы и простых окон, на большом разрешении упирается в CPU.

**Векторная 2D:** пути, кривые Безье, заливка по правилам (ненулевое число обходов, чёт-нечет), сглаживание; на GPU — тесселяция путей или специальные приёмы; библиотеки — по документации.

**Текст:**
- шрифт → разбор (TrueType или OpenType) → формирование строки (shaping: лигатуры, сложные письменности, направление) → растеризация глифов → атлас глифов → отрисовка прямоугольников;
- shaping нельзя пропустить для арабского, деванагари и др.; для него есть отдельные библиотеки (HarfBuzz и аналоги);
- SDF- и MSDF-шрифты — масштабирование без размытия; обычный SDF скругляет острые углы глифов, MSDF их сохраняет;
- перенос строк и ширина символов зависят от Юникода, а не от числа байт;
- лицензия шрифта — `game-dev-coach`, справка про ассеты.

**Интерфейс (GUI):**
- немедленный режим (immediate mode: интерфейс заново описывается каждый кадр, состояние у приложения) против сохраняемого (retained: дерево виджетов живёт между кадрами);
- раскладка (layout), обработка ввода и фокуса, перерисовка только изменённого, масштаб HiDPI;
- доступность (клавиатура, контраст, чтение с экрана) закладывается с начала.
Выбор библиотеки GUI — по проекту, кандидатов проверяет `dependency-audit`; устройство экранов в заметке `Дизайн` — `project-stages`.

**Визуализация данных:** график — отображение данных в положение, длину, цвет; оси и масштабы, большие ряды — прореживание или агрегация перед отрисовкой, обновление в реальном времени — кольцевой буфер; цветовые палитры, различимые при нарушениях цветового зрения.

**Примеры на другой задаче:** спрайт, бегущий по экрану; надпись «Hello» из атласа глифов.
